# TipHouse

TipHouse is a production-oriented donation platform inspired by TipMe, with PromptPay-style donation flow, realtime OBS alerts, dashboard, admin audit surfaces, and deployment scaffolding.

The original static prototype is still available in `index.html`, `styles.css`, and `app.js`. The production stack lives in:

- `apps/frontend`
- `apps/backend`
- `packages/types`
- `docker-compose.yml`

Read [PRODUCTION.md](./PRODUCTION.md) for setup and deployment steps.
